# 控制台和聊天页改版

日期 2026-10-26。设计稿用户已确认（本地 HTML，未入库），要求保留原来的 logo。

## 目标

用户提了四个问题：界面简陋、找东西难、常用流程绕、首页没用。设计稿的回答：

1. 共用一套视觉：保留「纸与铜」，侧栏改深色，四种固定状态色，数字等宽。
2. 导航分组（首页 / 日常 / 搭建 / 管理），顶栏去掉，账号和偏好收进侧栏底部；加 ⌘K 全局搜索。
3. 首页：先看要处理的事，再看今天的数字、最近任务、Agent 状态。
4. 任务列表和详情：标题用对方的第一句话；详情里回答和过程并排。
5. Agent 页分页签、能力开关、常驻发布条；接入外部服务合成一页。
6. 聊天页用同一套颜色。

## 顺序

每一段单独提交，先测试后实现。每段做完起栈走一遍再进下一段。

1. **外壳**：深色侧栏、分组导航、侧栏底部的账号菜单，删顶栏。
2. **⌘K 全局搜索**：页面和分段、Agent、按任务 ID 跳转。
3. **首页**。
4. **任务列表、任务详情**。
5. **Agent 页、接入外部服务**。
6. **聊天页**。

## 这份计划替产品做的决定

- **logo 不变**：继续用 `public/` 里的两张图（`HermesMark`），设计稿里的字母方块不用。
- **「工具与技能」改名「能力」**：设计稿的叫法。路径（`/tooling`）不变，旧链接继续能用。
- **语言、主题、退出收进侧栏底部的菜单**：多一次点击，换来内容区上方 64 px。退出是低频操作。
- **全局搜索只搜已经有接口的东西**：页面和分段、Agent 名称、任务 ID。设计稿里「搜密钥名、出网地址、任务内容」要么需要新接口，要么要把敏感列表拉到前端过滤，这一轮不做，搜索框里也不暗示能搜。
- **首页的数字只用能算准的**：任务列表接口有分页时，不在前端用一页数据算「今天的任务数」「成功率」——那会是一个看起来准确的错数。缺什么接口在第 3 段开头补后端，或者不放这个数。
- **任务列表的「做了什么」列**：需要按 Run 汇总工具调用的接口，现在没有。第 4 段决定是补接口还是不做这一列。

## 不做

- 不换组件库，仍然是 Ant Design。
- 不改权限：侧栏按角色隐藏仍然只是不邀请注定失败的点击，后端拒绝才是判据。
