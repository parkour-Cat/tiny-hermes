# 使用体验专项检查

用户授权：继续键盘与视觉、多角色操作、异常恢复三项检查。在独立本地环境实施与验证，不推送或合并。

## 这份计划替产品做的决定

- 通过已有页面交互和公开 HTTP 接口验证；延续前轮测试边界，不通过数据库读写代替验收。
- 异常时优先保留用户输入；网络恢复后由用户决定重试，不能静默重复提交。
- 键盘检查覆盖聊天自定义菜单、控制台表单弹窗及焦点；视觉检查覆盖深浅主题、窄屏和长文本。
- 多角色使用独立测试身份；服务重启只针对独立测试栈，原账号和真实渠道不参与。

## 清单

- [ ] 异常提交与恢复：输入保留、重试、刷新及服务重启。
- [ ] 键盘与视觉：菜单、弹窗、焦点、对比度、长文本与窄屏。
- [ ] 平台管理员、空间管理员、开发者、只读成员的真实接口与页面操作。
- [ ] 回归、复核、本地更新、证据记录和提交。
