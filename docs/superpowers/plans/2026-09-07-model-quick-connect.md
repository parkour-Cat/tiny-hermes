# 模型接入简化

用户要求：整体简化为填服务地址、API Key，再选择模型。保留平台管理员权限，不改既有 AgentVersion。

实现：默认显示简短接入表单；获取服务的 `/models` 列表、搜索选择后保存。Key 到最终保存时才加密入库，名称自动生成；已有凭据可复用。地址或 Key 变化后清除旧列表；获取失败允许手填模型名。原完整表单用于手动精确配置及编辑。

这份计划替产品做的决定：快速接入默认配置 8192 token 上下文运行限额、1024 token 输出限额，而非声称这是模型最大能力。表单明确标注可调整；图片关闭、窗口共享、用量质量 unavailable、价格未知。用户可在可选设置中覆盖限额，完整配置保留计价和其他字段。

获取列表不先创建模型、凭据或永久出站规则。平台管理员的此次请求产生一个短时数据库许可，仅允许当前查询访问所填主机；代理按许可 id 查库并保留地址、端口检查。许可到期后失效，请求结束时删除。未认证、非平台管理员、缺少 CSRF 均不得查询；响应仅返回去重后的模型 id，不透传提供方响应正文或密钥。

验证：真实 HTTP 服务器与代理覆盖列表、授权、过期与错误；前端覆盖三项输入接入、换连接清空旧结果、失败恢复和凭据复用；最后浏览器走查和本地服务构建更新。
