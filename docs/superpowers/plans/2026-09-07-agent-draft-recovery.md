# Agent 配置修改刷新恢复

用户授权继续处理剩余使用体验问题。本轮沿用页面操作、公开 HTTP 接口及真实浏览器测试范围。复核基线为 `22ade55`。先失败测试再实现，测试与实现分开提交；最后本地更新，不推送合并。

## 这份计划替产品做的决定

- 仅在当前标签页暂存未保存的表单修改，按已登录控制台用户、工作空间和 Agent 隔离。刷新后须身份和服务端读取成功才恢复；只读角色不恢复编辑内容。
- 名称、别名和版本化配置一起暂存，但沿用各自的服务端保存按钮，不自动保存或发布。
- 暂存附带原草稿修订号和原名称／别名。服务端已有变化时不自动覆盖；显示暂存差异供查看复制，用户明确放弃后载入最新内容。
- 保存成功只清理实际已保存的部分；失败保留修改。重新载入及明确放弃离页时清理对应暂存。存储不可用或数据损坏时提示，不妨碍手动保存。
- 不承诺关闭标签、跨设备恢复；不保存登录凭据，不改变已发布 AgentVersion 内容。
