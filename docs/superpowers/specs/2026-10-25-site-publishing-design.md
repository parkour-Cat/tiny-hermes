# 发布静态网站：`site.publish`（v2.26）

日期 2026-10-25。产品设计 §1.26、§16.1。

## 要解决什么

用户想让 Agent「做一个网站，做完给我一个访问链接」。现在做不到，原因有三个：

- 沙箱没有入站网络；
- Run 结束就销毁沙箱（§1526）；
- 工作区文件只能以附件形式下载。

## 范围

**做：**
- 把工作区里一个目录的**已提交快照**，作为静态网站发布出去，得到一个链接。
- 支持 HTML、CSS、前端 JavaScript、图片、字体、JSON 等静态文件。

**不做：**
- 服务端代码、数据库、后端接口；
- 让沙箱在 Run 结束后继续开着并转发端口（与 §1526、§16.4 冲突）；
- 自定义域名、访问统计；
- 发布后修改内容。要改就重新发布，会得到一个新链接。

## 怎么用

Agent 绑定 `site.publish` 后，在做完网站的那一轮之后调用：

```json
{"name": "site.publish", "arguments": {"path": "site", "title": "记账本"}}
```

- `path`：工作区里的目录，相对 `/workspace/data`，默认 `site`；必须包含 `index.html`。
- `title`：可选，给控制台列表看，最多 100 字。

平台回答一个工具结果，包括链接、过期时间、谁能打开。Agent 在最终回复里把链接告诉用户。

和 `todo.write` 一样，这是**平台自己回答的工具**，不进沙箱。

## 发布的是哪个版本

**调用那一刻，这个会话最新的已提交工作区版本。**
- 每一轮会改文件的工具调用之后，worker 都会提交一次检查点（设计 §8）。所以上一轮写好的文件，到下一轮调用 `site.publish` 时已经在版本里了。
- 同一轮里如果先写文件、再发布，写文件那次的结果还没提交，发布的会是上一个版本。工具说明里写明：**发布要单独放在一轮里**。

发布记录钉住这个版本 id。之后会话再怎么改，链接里的内容都不变。

### 发布记录会不会失效

- **只会被会话删除带走。** 工作区版本平时不会被回收：垃圾回收只删「没有任何版本行引用」的对象，版本行只会随会话删除级联删掉。
- 发布记录对版本行设外键并级联删除，所以会话或工作区被擦除时，链接一起失效。**擦除优先于分享。**

## 检查（发布时一次做完，失败就整体拒绝）

- 目录存在于那个版本里，并且包含 `index.html`。
- 文件数不超过 500 个，总大小不超过 50 MB。
- 每个文件的扩展名都在白名单里：
  - 网页：`html` `htm` `css` `js` `mjs` `json` `map`
  - 图片：`svg` `png` `jpg` `jpeg` `gif` `webp` `ico`
  - 字体：`woff` `woff2`
  - 文本：`txt` `md` `csv` `xml`

  不在白名单里的文件不会被悄悄跳过，而是**拒绝发布，并列出是哪些文件**。悄悄跳过会让网站缺东西，而且没人知道为什么。

拒绝时以失败的工具结果告诉模型原因，模型可以改了再发。

## 链接与访问

**链接形如 `{SITE_PUBLIC_URL}/s/{token}/`。**
- `token` 是 32 字节的随机串（URL 安全的 base64 编码），库里只存它的 sha256。
- 链接只在发布那一刻出现一次：在工具结果里，也会出现在会话记录里。
- 控制台列表能看到标题、过期时间、状态，但看不到 token 本身。要再拿到链接，就重新发布。

**谁能打开（决定：默认只有成员，管理员可以放开）：**

| 可见性 | 谁能打开 | 谁能设置 |
|---|---|---|
| `members`（默认） | 这个工作空间的成员，需要登录 | 发布时的默认值 |
| `link` | 拿到链接的任何人 | 只有 `workspace_admin`，可以随时改回 `members` |

**过期（决定：7 天）：**
- 默认 7 天（`SITE_PUBLICATION_TTL_DAYS`，范围 1 到 90）。
- `workspace_admin` 和 `developer` 可以延长，每次从「现在」起再加一个默认期限，最长不超过发布后 90 天。
- 任何成员都可以撤销。撤销立刻生效，不能恢复。

### 成员访问怎么验证

预览服务和控制台在**不同的来源**上（见下面「安全」），拿不到控制台的登录 cookie，所以要换一次票：

1. 没有有效预览凭证的请求，预览服务回一个说明页，上面有一个「登录后打开」按钮，指向控制台 API 的 `GET /api/v1/sites/open?t={token}`。
2. 控制台 API 用控制台的登录状态检查：这个人是不是该工作空间的成员，链接有没有过期、有没有被撤销。通过后签发一张 **60 秒、只能用一次**的票据（HMAC），重定向回预览服务的 `/s/{token}/__auth?ticket=...`。
3. 预览服务验票，设置一个只对这个网站路径有效的 cookie，然后重定向到网站首页：
   - 作用路径 `Path=/s/{token}/`，有效期 12 小时；
   - `HttpOnly`、`SameSite=Lax`，HTTPS 下加 `Secure`；
   - 内容是 HMAC 签名的「发布 id、用户 id、到期时间」。
4. 之后每次请求都按这个 cookie 放行；同时仍然检查发布有没有过期或被撤销，撤销立刻生效。

签名密钥是 `SITE_SIGNING_SECRET`，API 和预览服务共用，**不复用控制台的 cookie 密钥**：预览服务被攻破时，不能借此伪造控制台的登录。

## 安全

被发布的 JavaScript 是模型写的，会在**打开链接的人的浏览器里**执行。

- **独立来源。** 预览服务用 `SITE_PUBLIC_URL`，必须和控制台、API 不是同一个来源（不同域名，或者至少不同端口）。启动时检查，同源就拒绝启动。这样模型的脚本拿不到控制台的 cookie，也调不了控制台的接口。
- **响应头：**
  - `Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; form-action 'none'; base-uri 'none'`。网站可以运行脚本、加载自己的文件，但不能把数据发到别处，也不能被别的页面嵌入。
  - `X-Content-Type-Options: nosniff`。`Content-Type` 按扩展名决定，不按内容猜。
  - `Referrer-Policy: no-referrer`。链接里的 token 不会随引用来源泄露出去。
  - `Cross-Origin-Resource-Policy: same-origin`。
  - `Cache-Control: private, no-cache`。撤销后，浏览器不会继续用缓存显示内容。
- **同一来源下的不同网站**能互相读到对方的文件，前提是知道对方的 token：CSP 只能限制到「同一来源」，而成员凭证是按路径限制的。所以：
  - token 不可猜；
  - 生产部署可以把 `SITE_PUBLIC_URL` 设成每个网站一个子域名：值里写 `{token}`，比如 `https://{token}.sites.example.com`，就能彻底隔开。

  **首版只做路径形式，子域名形式不做。** 这条风险写进运维手册。
- **只读。** 预览服务只读数据库和对象存储，不接受写请求（只允许 GET 和 HEAD），不访问沙箱，也不经过出网代理。
- **审计。** 发布、撤销、延长、改可见性，各写一条审计事件，记录是谁、哪个 Run、哪个网站。

## 部署

- **新进程 `site`：** 用同一个镜像，入口是 `tiny-hermes site`，有自己的端口。本机 Compose 是 `127.0.0.1:8090`。
- **配置项：**
  - `SITE_PUBLIC_URL`：链接的前缀；
  - `SITE_SIGNING_SECRET`：至少 32 个字符；
  - `SITE_PUBLICATION_TTL_DAYS`：默认 7。
- **不配 `SITE_PUBLIC_URL` 时，发布功能关闭：** Agent 仍然可以绑定 `site.publish`，但调用时会得到失败的工具结果，说明「本部署没有开启网站发布」。

## 控制台

- **工作空间下新增「网站」页面：** 列出标题、来自哪个 Run、谁能打开、过期时间、状态，提供撤销、延长按钮；`workspace_admin` 还能看到「改为任何人可打开」。
- **Run 详情页：** 工具调用里能看到发布结果，其中就有链接。

## 测试计划

- **单元：** 路径和扩展名检查、token 和票据的签名与过期、响应头、同源时拒绝启动。
- **集成（真 Postgres、真对象存储）：**
  - 发布 → 用链接取到文件，内容和 sha256 对得上；
  - 成员访问要换票，非成员被拒绝；
  - 撤销后立刻 404，过期后 404；
  - 会话修改之后，链接里的内容不变；
  - 会话删除后，链接失效。
- **端到端：** 用 DeepSeek 跑一个长任务，「做一个网站，做完给我链接」，然后用浏览器打开链接验收。

## 这一版不承诺

- 网站之间的严格隔离：首版只有路径形式，见上面「安全」。
- 网站在手机上好不好看、能不能用：这是模型的产出质量问题，不是平台的。
