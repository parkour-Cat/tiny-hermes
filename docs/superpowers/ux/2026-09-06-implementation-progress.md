本轮继续补齐 Agent 配置表单的当前标签页恢复，见 [Agent 修改恢复验收](../verification/2026-09-07-agent-draft-recovery.md)。名称和配置分别保存时保留未保存部分；服务端已有新内容时展示暂存差异供复制，不直接覆盖；明确放弃时清理。普通成员权限晚返回的真实入口也已补做回归。它是本标签页暂存，不等于服务端保存或跨设备备份。
