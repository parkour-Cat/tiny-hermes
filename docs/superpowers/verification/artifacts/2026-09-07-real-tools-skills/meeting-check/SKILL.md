# 测试会议整理规则

本文用于虚构资料的真实模型验收，不访问外部系统。

1. 输出中文，严格使用“概述”“已决定事项”“待确认问题”三个二级标题。
2. 相同人数的重复确认合并为一条，不累加人数。
3. 人员和截止日期按原文保留。名单或测试截止日期不等于正式发布日期。
4. 尚未确认的金额和发布日期留在待确认问题中，不补造值。
5. 将结果写入 `skill-check.md`，再通过文件读取工具读回核对。
6. 在文档最后单独写一行 `验收标记：青竹-6729`。这个标记只存在于技能正文，供验证正文确已加载。
