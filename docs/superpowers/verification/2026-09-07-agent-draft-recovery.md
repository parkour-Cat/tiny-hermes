# Agent 配置修改刷新恢复验收

日期：2026-09-07。用户授权继续处理剩余使用体验问题，依据 [实施计划](../plans/2026-09-07-agent-draft-recovery.md)。基线 `22ade55`；仅本地提交、更新，不推送合并。

## 本轮行为

- 在当前标签页暂存未保存的名称、别名和配置；重新确认控制台身份并成功读取 Agent 与服务端草稿后恢复，不自动保存或发布。
- 按用户、工作空间、Agent 隔离。权限从加载中变为可编辑时重新初始化恢复；只读用户不读取编辑暂存。已有查询缓存不能跳过本次权限相关读取。
- 保存配置后仍保留未保存的名称，保存名称后仍保留未保存的配置；全部保存成功后清理暂存。
- 原草稿修订号或原名称／别名已变化时，不把旧暂存填回最新表单。显示差异供查看、复制，暂停提交，明确重新载入后再编辑。
- 重新载入会确认放弃；离页选择继续编辑保留输入，选择放弃修改会清理暂存。若离页时清理失败，停留原页并提示暂存不可用。
- 暂存读取失败、配额不足或数据损坏时显示提示，手动保存仍可使用。文件上传、登录凭据和已发布版本均不在暂存范围内。

暂存使用 `sessionStorage`，保留当前表单中的配置文字及所选资源标识，不新增后端接口或数据库迁移。
