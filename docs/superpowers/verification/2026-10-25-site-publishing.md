# 发布静态网站 `site.publish`：实现与测试

日期 2026-10-25。分支 `feat/site-publishing-design`。产品设计 v2.26（§1.26、§16.1），[设计](../specs/2026-10-25-site-publishing-design.md)。

## 做了什么

| 部分 | 内容 |
|---|---|
| 领域 | 目录检查（必须有 `index.html`、500 个文件、50 MB、扩展名白名单，不合格就整体拒绝并列出原因）、按扩展名定媒体类型、token（只存哈希）、带用途和有效期的 HMAC 签名、响应头、同源判断 |
| 存储 | 迁移 0081：`site_publications`（外键指向钉住的工作区版本，随它级联删除；开启行级安全）、`site_ticket_uses`（票据只能用一次） |
| 服务 | `SitePublisher`：从会话最新的已提交版本发布、按 token 解析、按钉住的版本取文件、列表、撤销、延长（最长 90 天）、改可见性，全部写审计 |
| 工具 | `site.publish`：平台自己回答的工具，告诉模型要单独一轮发布；目录不合格时把原因回给模型；部署没开启时说明 |
| 控制台接口 | `/api/v1/sites`：列表（不含链接）、撤销（任何成员）、延长（developer 和 admin）、改可见性（只有 admin）；`/open` 在控制台这边验证登录，签发 60 秒的一次性票据 |
| 预览服务 | `tiny-hermes-site`，独立来源，只接受 GET 和 HEAD；成员网站显示一个「登录后打开」的说明页，换票后设置只对该网站路径有效的 12 小时凭证 |
| 配置 | `SITE_PUBLIC_URL`、`SITE_SIGNING_SECRET`、`SITE_PUBLICATION_TTL_DAYS`；三者不配套、或和控制台同源时，进程拒绝启动 |
| 部署 | Compose 新增 `site` 服务，放在 `sites` profile 里（8090 端口）；运维手册第 18 章 |
| 控制台页面 | 「记录 → 网站」：列表、撤销、延长、改为任何人可打开（要确认） |

## 测试过了

- **单元测试：**
  - 网站领域逻辑 32 条：检查规则、签名、响应头、同源判断；
  - 工具声明和参数 8 条；
  - 后端单元测试全量 2819 passed。
- **集成测试（真 Postgres、真对象存储），网站相关 23 条：**
  - 发布后从链接取到的内容和 sha256 一致；会话之后再改，链接里的内容不变；不合格的目录被拒绝并给出原因；
  - 撤销、过期后取不到；删除工作空间后，链接随之失效；
  - 延长从「现在」起算，上限是发布后 90 天；审计事件依次是发布、改可见性、撤销；
  - 票据只能用一次；一个网站的票据或凭证打不开另一个网站；撤销后即使带着有效凭证也是 404；
  - 预览服务的响应头和内容类型都对；路径穿越返回 404；POST 返回 405；成员网站没有凭证时显示说明页（401），说明页上是控制台的 `/open` 链接；
  - worker 真的执行一轮 `site.publish`：Run 完成，会话记录里有链接，库里有一条发布记录；目录不合格时拒绝原因回给了模型；没开启时会说明；
  - 控制台接口：每种角色的权限；非成员被拒；`/open` 签发的票据能验证；可见性改成 `link` 后直接跳转；撤销后 404。
- **行级安全：** 测试最先抓出 `site_publications` 漏开了行级安全，补上后通过。
- **其他：**
  - 非沙箱集成测试全量：1159 passed、1 failed，失败的就是上面那条行级安全，补上后已单独通过；
  - `alembic check` 没有差异；
  - 前端测试 411 passed（网站页面 5 条）；
  - 本机栈带 `sites` profile 起来，预览服务健康，迁移到 0081 并开启了行级安全。

## 这一遍没能证明什么

- **没有用真实模型、真实浏览器走过一遍：** 「做网站 → 发布 → 用浏览器打开链接」的端到端验收，单独用 DeepSeek 跑，另写记录。
- **成员登录换票这条路只在测试里走过：** 测试里预览服务和控制台是用 `TestClient` 分别调用的，没有在真浏览器里跨两个来源走过一遍。
- **同一来源下网站之间不是严格隔离的：** 见设计文档和运维手册 §18.3，首版不做子域名。
- **前面还应该有反向代理和 TLS：** 只在本机 HTTP 下跑过。HTTPS 下凭证会加 `Secure` 标记，这一点只读过代码，没有实际跑过。

## 不声称什么

- 不声称这能替代正式的网站托管：没有自定义域名、没有访问统计，也没有内容审查。
