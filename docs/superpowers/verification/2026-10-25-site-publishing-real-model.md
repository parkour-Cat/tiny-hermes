# 发布静态网站：真实模型 + 真实浏览器的端到端验收

日期 2026-10-25。本机 Compose 栈，分支 `feat/site-publishing-design`。模型是 DeepSeek `deepseek-chat`，浏览器是 Playwright Chromium。
设置为 `SITE_PUBLIC_URL=http://localhost:8090`、`CONSOLE_BASE_URL=http://127.0.0.1:3000`。

## 任务

让 Agent 做一个「共享单车 9 月数据看板」：
- 用给定的 `gen.sh` 流式生成 6000 万条骑行记录；
- 用 awk 算出 5 个 JSON 数据文件；
- 做三个页面：总览、站点排行、按天统计，用原生 JS 和 SVG，不能有外部链接；
- 用给定的 `verify.sh` 验收（每跑一次都要把数据全部重算，约 1 分钟），通过后调用 `site.publish`，在回复里给出链接。

测试本身先验证过：我写的参考实现能通过 24/24，空网站只能过 4/24。

## 经过

1. **第一个 Run（13:41–13:47，约 6 分钟，56 轮）**
   - 模型报告 `verify.sh` 24/24，并给出了链接。
   - 它自己指出：它写下的 `verify.sh`，sha256 和我给的不一致。比对后发现只差一个反斜杠（`\\(` 写成了 `\(`），在双引号里行为完全相同。
   - 我用自己那份 `verify.sh` 对它的网站重新验收，也是 **24/24**。
   - **用浏览器打开后，三个页面都卡在 Loading…**：页面调用了 `asJSON`，但哪里都没有定义。`verify.sh` 只做静态检查，沙箱里也没有 JS 引擎，所以模型发现不了。
   - 它为了通过「不能有外部 URL」这条检查，把 SVG 命名空间用字符串拼接的方式写出来。这个命名空间只是标识符，不是真的外链，说明那条检查写得过严了。
2. **在同一个会话里发第二个 Run，把浏览器报错告诉它（13:56–13:59，约 3 分钟，9 轮）**
   - **13:57:12，`verify.sh` 运行中硬杀 worker**：
     - 13:57:32 租约过期，Run 被打断；
     - 13:57:33 恢复并重新拿到租约；
     - 13:57:34 新沙箱从检查点恢复了工作区，里面已经有修复后的文件。
   - 模型重新跑完验收，13:59:43 重新发布，回复里给出新链接，并坦白说沙箱里没有 JS 引擎，修复只是靠检查代码确认的。
3. **浏览器验收新链接**
   - 不登录打开链接：401「Sign in to open this site」；
   - 在控制台登录后，点说明页上的按钮：经过控制台的 `/open` 换票，回到网站首页；
   - 首页显示 6000 万次骑行、2.81 亿公里、平均 30.04 分钟、会员 70.0%，按小时的图表（早 8 点、晚 6 点高峰）、站点排行表（10 行）、按天的图表都正确渲染，没有脚本错误；
   - cookie：网站主机 `localhost` 上只有 `site_pass`，控制台的登录和 CSRF cookie 只在 `127.0.0.1` 上。
4. **控制台「网站」页面**：列出两个网站；在页面上撤销旧的那个，状态立刻变成「已撤销」，旧链接返回 404。审计依次是 `site.published` 两次、`site.revoked` 一次。

## 途中发现并修好的平台问题

- **网站和控制台只是端口不同，不够**：cookie 不区分端口。准备浏览器验收时发现，同一主机名下，浏览器会把控制台的登录 cookie
  发给网站，网站上的脚本也能读到控制台的 CSRF cookie。现在配置要求两者是不同的主机名，否则拒绝启动（另有测试）。
- **控制台 `/sites` 路径没有登记跳转**：会跳回工作空间列表，已补上。

## 这一遍没能证明什么

- **任务不长**：两次 Run 加起来不到 10 分钟，远没有到一小时。DeepSeek 写这个规模的网站很快；数据量放大后，变慢的是验收脚本，
  模型的轮数并没有变多。
- **故障只注入了一次**：在工具执行中硬杀了 worker。没有在检查点提交的那一刻杀，那个窗口不到一秒，很难卡准。
- **只验了成员可见的网站**：「任何人可打开」只在集成测试里走过，浏览器里没有试。
- **只在本机 HTTP 下跑过**，没有反向代理和 TLS。
- **网站质量是模型的事**：第一版就有运行时错误，平台不会替用户发现这种问题。

## 不声称什么

- 不声称模型做的网站经得起正式使用：距离那张卡片的数字太长被截掉了一点，这次只验证了数据正确、页面能用。
