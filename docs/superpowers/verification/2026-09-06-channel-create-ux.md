# 飞书新建流程验收

日期：2026-09-06。继续用户已授权的全产品使用体验整理，本轮落实 UX-14 的一次创建完整接入配置。

## 实现范围

- 新建表单与编辑表单共用接入方式字段；填写应用 ID、选择应用密钥后，可直接选择长连接并一次保存。
- 创建接口接受 `transport`，后台创建和编辑共用长连接检查：非空白应用 ID、当前工作空间内有效的应用密钥引用。无效配置在写入绑定前被拒绝。
- 保留未指定接入方式时默认 Webhook，以及仅接收消息的 Webhook 不要求应用密钥的行为。未知字段仍拒绝；已有绑定和发布版本不变，不需要数据库迁移。
- 长连接选定后清空必填项，表单会阻止提交。保存长连接后提示部署管理员重启 scheduler，再检查连接与消息收发；不会把保存成功当成已连接。
- 新建说明解释两种接入方式的公网回调要求。应用密钥可留空的说明限定为仅接收消息的 Webhook。

- 没有执行全仓测试、compose-e2e 或全尺寸／全主题视觉验收。
