# 生成文件与工具用量验收

日期：2026-09-06。范围：UX-11、UX-12，衔接第一批使用体验调整。

## 改动范围

- 控制台按任务的已保存检查点列文件；聊天端按本人会话的当前保存版本列文件。普通文件与工具输出附件分开，没有补造 Artifact。
- 列表返回版本标识；下载严格匹配版本和文件路径。版本变化返回 409，页面提示并刷新；不存在的路径 404；存储或清单校验失败 503。
- 控制台沿用任务读取权限，聊天端沿用会话归属检查。终端用户响应只含版本标识、路径、大小，不包含内部存储位置和摘要等管理字段。
- 文件列表支持刷新、失败提示、逐文件下载；长路径换行，文件区域有独立分隔。深浅主题均在真实页面检查。
- 工具执行前原子占用共享次数。HTTP/MCP 等待审批不扣次数，实际发送前扣；本地及平台处理器的失败尝试仍占次数。并行调用逐个受剩余额度约束。历史漏记数据不回填。

## 这一遍没能证明什么

- 聊天端真实企业登录与嵌入环境的下载体验尚未浏览器实测；对应页面、身份归属和文件接口由回归测试验证。
- 真实模型只跑了一次新任务；没有用真实外部 HTTP/MCP 写操作测试限额或审批，没有发送飞书消息。
- 没有覆盖所有故障、断电和大文件下载。文件大小在发送前检查，摘要在流结束时校验，不能声称在首字节发送前验证了整个文件；中途出错会中断下载。
- 工具次数是执行尝试的账目，在结果不确定或检查点回滚后不退款，可能大于最终保留的成功结果数。
- 移动端、所有浏览器、完整键盘无障碍及历史数据回填未验收。
