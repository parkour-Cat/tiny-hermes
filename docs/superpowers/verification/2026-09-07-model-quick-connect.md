# 模型接入简化验收

日期：2026-09-07。用户确认主流程应为“填地址、Key，再选模型”。设计决策见 [接入简化计划](../plans/2026-09-07-model-quick-connect.md)，产品规格同步补充快速接入的运行限额含义。

## 完成内容

- 默认表单只有服务地址与 API Key；也可以选择已有 Key。获取模型列表后提供搜索选择，再点击添加模型。
- 模型和凭据名称自动生成。名称、上下文与输出运行限额放在可选设置；默认为 8192 / 1024 token，明确说明不代表模型最大能力。价格未知、图片默认关闭；精确参数与价格仍可通过完整配置／编辑设置。
- 获取列表不持久保存密钥或提前创建模型。平台管理员的此次请求获得 60 秒有效的主机许可；只在本次发现请求生效，代理仍执行地址和端口检查，查询不跟随重定向，最多等待 25 秒、响应最多 1 MiB。请求结束删除许可，异常终止时依赖到期失效，下次查询清理过期记录。
- 地址或 Key 变化后清除旧模型列表；服务拒绝 Key、不支持列表、请求失败都有中文提示，并可改为手填模型名。
- 保存模型失败后重试复用已成功存入保管箱的凭据。明文 Key 不写浏览器持久缓存或 React Query 缓存。
- 浏览器实测发现服务地址和 API Key 被密码管理器当作登录表单自动填充；改为 URL 输入类型及 new-password 提示。重新加载最新构建后两字段保持空白。

## 这一遍没能证明什么

- 真实浏览器用了已保存 Key 分支；输入新 Key 分支由组件测试和真实代理接口测试分别覆盖，没有重新复制用户密钥进页面。
- 模型列表中的模型不保证都支持对话、图片或工具。列表通常不提供容量和价格，因此没有从名字推测真实规格。
- 本轮未用新增测试接入再跑一轮 Agent，也未验证所有服务商；先前真实模型文件工具与技能执行记录仍是独立证据。
- 未做全部手机尺寸、密码管理器和浏览器组合的人工验收。

## 不声称什么

不把模型列表读取成功等同于模型推理成功；不把默认运行限额当作服务商规格，不把未设价格说成免费。不覆盖或替换原模型接入与 Agent 版本。本轮尚未推送、提 PR 或取得远程 CI 结果。
