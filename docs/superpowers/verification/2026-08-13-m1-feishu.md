## 2. What this environment did not do

- No `lark.ws.Client` / adapter code.
- No Feishu app id, secret, or tenant.
- No outbound WebSocket to Feishu.
- No disconnect-gap drill.

## 3. What an M2/M3 adapter would still have to do

Regardless of transport: map Feishu users to `ExternalIdentity` (they are not
workspace members); convert a message to a Run; dedup
`channel_binding_id + channel_event_id` for 7 days; when the Session head is
blocked, send a status card (reason, queue position, available actions) rather
than silently swallowing the message. Those rules are product, not this note.
