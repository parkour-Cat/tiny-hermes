### 3.1 Console behaviour covered by component tests

- Builder checklist PUTs `tools: ["file.list"]`. Default delivery is omitted
  from the draft body so published hashes stay stable. Enabling Chat
  Completions sends `{ enabled: true, sync_timeout_seconds: 60 }`. Rename is
  `PATCH` name/alias. Rollback confirms, then `POST /rollback` with
  `version_id`. Diff is field-level against `GET …/versions/{id}` spec.
- Playground send includes a UUID `Idempotency-Key` and `{ session_id, input }`.
  A `201` with `queue.status=session_blocked` shows the head's actions and
  posts resume to `queue.blocked_by_run_id`, not to the pending Run. 「新
  Session」 posts `{ session_mode: "persistent" }`.
- Run Detail lists CanonicalMessages, tool rounds, and files. Timeline payload
  is a folded `<details>`. Absent M2/M3 labels: `父子任务树`,
  `上下文和压缩事件`, `Token 和费用`. `产物` is the Files card title.
- Members invite posts `{ email, role }`. Unknown email surfaces
  `user_not_found` copy. API Key plaintext is shown once and disappears after
  dismiss; the prefix remains. Model endpoint `base_url` is fetched only for a
  platform administrator.
- Locale default stays `zh-CN`. Chrome switcher reaches `en-US`. Theme
  persists as `light` | `dark`. Nav is Agent / 运行 / 成员 / 模型端点 / API
  Keys. Approvals is absent.

### 3.2 Playwright (written, not executed here)

`tests/e2e/console.spec.ts` keeps the draft→publish→run→retry walk and adds:

- bind `file.list`, Playground send, optional blocked-queue assertion if 暂停
  is still visible, rollback to v1;
- locale switcher to English and back.

Those walks need the API + Web + Worker stack on `:8000` / `:3000`. This
environment did not have those processes. Do not treat them as green.

Artifact download in Playwright is not added: a deterministic Agent in this
stack does not reliably produce an Artifact on the existing walk. Download is
covered by the Run Detail / Playground component tests (fetch with
`X-Workspace-Id`).

Run list pagination is still unpaginated; the existing list page was not
given `limit`/`cursor`.
