# 渠道与审批体验验收

日期：2026-09-06。工作空间：真实模型测试（819d6559-91f3-478d-911a-5a62aeef1d48）。
本轮只调整控制台、聊天前端与文案，不修改后台审批权限或已发布 Agent 版本。

## 调整范围

- 渠道先选择飞书机器人或网页聊天；按场景加载相应配置。飞书加载失败仍可进入网页场景。
- 网页配置说明开放 Agent、登记网站身份验证、由业务系统接入并验证三个步骤。已有发布版本不代表已开放用户访问，已保存验证配置也不代表接入完成。
- 飞书编辑支持一次保存应用凭据和长连接。创建接口明确禁止 `transport` 字段，本轮保留新建 Webhook 后编辑的流程，并在创建窗口说明。
- 管理员默认看“待我处理”，其他成员默认“等待他人”；控制台不提供终端用户确认的批准／拒绝按钮。
- 请求目标与参数直接可读，完整规范化请求保留在展开区域，避免使用生成的概括代替实际请求。两端限制参数区域高度并换行。
- 审批待处理和历史都支持翻页；类型、历史状态与偏移量交给服务器筛选。

## 这一遍没能证明什么

- 没有配置真实飞书应用或向外发送消息，因此不能证明新接入能实际收发。
